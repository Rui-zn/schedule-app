# 日程表 v1.0.1

工程化更新：GitHub Actions 持续集成（每次 push 自动测试 + 构建）、分支保护、界面截图与文档完善。

## ✨ 变更

- 新增 GitHub Actions：push 到 main 自动运行测试与打包；推送 `v*` 标签自动发布 Release（含 exe）
- 主进程支持 `SCHEDULE_USER_DATA` 环境变量（演示 / 便携用途）
- 新增演示数据脚本 `scripts/demo-data.js`
- README 增加界面截图与自动发布说明

## 📦 使用

下载 `ScheduleApp-1.0.1-portable.exe` 双击运行即可（绿色便携，数据存于 `%APPDATA%\日程表\`）。
建议放在固定目录后再开启「开机自启」。

## 🔒 校验

- exe 为 GitHub Actions（windows-latest）构建产物，未签名（Windows SmartScreen 可能提示「未知发布者」，选择「仍要运行」即可）
