# 📅 日程表（Schedule App）

一个运行在 Windows 本地的日程表桌面应用：**Electron + SQLite（sql.js）**，常驻系统托盘后台运行，支持开机自启。

## ✨ 功能

- **日程增删改查**：标题、开始/结束时间、全天、备注
- **完成状态**：一键勾选完成，自动取消对应提醒
- **重复日程**：每天 / 每周 / 每月，支持间隔与结束日期（月末自动钳制）
- **分类标签**：自定义名称与颜色，删除分类后日程自动变为「无分类」
- **桌面提醒**：提前 N 分钟系统通知；全天日程固定当天 09:00 提醒；应用退出期间错过的提醒在下次启动时补发（24 小时内）
- **列表 / 月历双视图**：按天分组的近期列表 + 可翻月的月历，支持关键词搜索、分类筛选
- **后台运行**：关闭窗口最小化到托盘，托盘菜单可打开 / 退出
- **开机自启**：在用户启动文件夹创建快捷方式，开机后静默启动到托盘；设置页一键开关
- **数据目录自定义**：默认存 C 盘（`%APPDATA%\日程表\`），可更换到任意磁盘目录，切换时可选移动现有数据，一键恢复默认

## 🚀 快速开始

要求：Windows 10/11，[Node.js](https://nodejs.org/) ≥ 20（无需任何原生编译工具）。

```bash
npm install   # 安装依赖（含 Electron 下载，请耐心等待）
npm start     # 启动应用
```

其他命令：

```bash
npm run start:hidden   # 静默启动（仅托盘，模拟开机自启）
npm test               # 数据层 + 自启模块测试（纯 Node，无需图形界面）
npm run test:ui        # UI 端到端自检（真实页面 CRUD + DOM 校验）
npm run dist           # 打包单文件 portable exe（输出到 dist/）
```

## 📖 使用说明

| 操作 | 方法 |
| --- | --- |
| 新建日程 | 日程页右上角「＋ 新建日程」，或在月历中点击日期后「＋ 当天新建」 |
| 编辑 / 删除 | 悬停日程条目右侧的 ✏️ / 🗑 |
| 标记完成 | 勾选条目左侧复选框 |
| 分类管理 | 左侧「分类」页：添加 / 编辑 / 删除，选颜色 |
| 开机自启 | 左侧「设置」页打开开关（在启动文件夹创建 `日程表.lnk`） |
| 数据目录 | 左侧「设置」页「选择目录…」更换数据存放位置，「恢复默认」回到 C 盘 |
| 后台运行 | 直接关闭窗口即可，应用驻留托盘；托盘右键「退出」才真正退出 |

## 📁 数据位置与备份

- 默认数据目录：`%APPDATA%\日程表\`（C 盘）；可在「设置」页更换为任意目录，并一键打开当前目录
- 数据库：`schedule.db`（SQLite，位于数据目录）；设置：`settings.json`（始终在 `%APPDATA%\日程表\`）
- **备份**：直接复制 `schedule.db` 即可；数据库文件损坏时会自动备份为 `schedule.db.broken-*` 并重建
- **换目录时**：选择「移动现有数据」会把 `schedule.db` 带到新目录；若新目录已有数据文件则直接使用新目录的数据（不覆盖）

## ❓ 常见问题

- **自启没有生效？** 检查「设置」页开关状态与路径提示；开发模式（`npm start`）下创建的快捷方式指向 `node_modules` 里的 electron.exe，打包版指向 exe 本体。
- **提醒没弹出？** 确认「设置」页的「桌面提醒」开关已开启；通知需要应用进程存活，退出期间的提醒会在下次启动时补发。
- **如何彻底退出？** 托盘图标右键 → 退出（点窗口 ✕ 只是最小化到托盘）。
