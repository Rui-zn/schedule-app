# 日程表 v1.0.0 首个发布

本地日程表桌面应用（Windows 10/11），Electron + SQLite（sql.js），无需安装、单文件便携运行。

## ✨ 功能

- 日程增删改查：标题、开始/结束时间、全天、备注
- 完成状态：勾选完成自动取消对应提醒
- 重复日程：每天 / 每周 / 每月，支持间隔与结束日期（月末自动钳制）
- 分类标签：自定义名称与颜色
- 桌面提醒：提前 N 分钟系统通知，全天日程固定 09:00，错过的提醒下次启动补发（24h 内）
- 列表 / 月历双视图：搜索、分类筛选
- 托盘后台运行：关窗最小化到托盘
- 开机自启：启动文件夹快捷方式，静默启动到托盘（设置页开关）
- 数据目录自定义：默认 C 盘，可换任意磁盘目录并移动数据

## 📦 使用

下载 `日程表 1.0.0.exe` 双击运行即可（绿色便携，数据存于 `%APPDATA%\日程表\`）。
建议放在固定目录后再开启「开机自启」。

## 🔧 开发者

源码见仓库根目录；`npm install && npm start` 开发运行，`npm test` / `npm run test:ui` 测试，
完整项目文档见 `docs/PROJECT.md`。
